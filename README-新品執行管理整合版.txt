GUXON 新品管理平台｜策略＋執行整合版

這次不是新做一套獨立網站，而是在同一個 Project 底下加入第二個模組：
1. 新品策略管理（原本 6 階段／41 項策略工作）
2. 新品執行管理（新增 9 大工作區／68 項跨部門執行工作）

【安裝步驟】
1. 先備份目前可正常使用的 guxon-project-management 資料夾。
2. 將本更新包內容覆蓋到原本 guxon-project-management。
3. 不要刪除、不要覆蓋你原本的 .env.local。
4. 到 Supabase > SQL Editor 執行：03_新品執行管理模組.sql
5. PowerShell 在專案資料夾執行：npm run dev
6. 開啟 http://localhost:3000

【既有 HALO 專案】
進入 HALO → 點上方「新品執行管理」→ 點「建立新品執行模板」。
系統會為 HALO 建立 9 大工作區與 68 項標準工作，不會刪除原本策略資料。

【之後新增新品】
按「＋新增專案」後，系統會同時建立：
- 策略管理：6 階段／41 項工作＋通關檢核
- 執行管理：9 大工作區／68 項工作

【新品執行管理功能】
- 商品資料與行政
- 包裝與基礎設計
- 商品攝影
- 影音製作
- 銷售頁製作
- 電商與通路上架
- 行銷上市準備
- 客服與倉儲準備
- 上市前總檢核
- 工作負責人
- 審核人
- 開始日／截止日
- D-Day 自動排程
- 高／中／低優先級
- 未開始／進行中／待審／已完成／卡關／不適用
- 前置任務依賴
- 備註／連結
- 逾期與 7 天內到期提醒
- 分類進度與整體執行進度
- 依上市日重新排程
- 多人 Realtime 同步

【不適用 N/A】
某新品若不需要某工作，例如不拍影片，可以把狀態改成「不適用」。
不適用項目不會被算進執行完成率分母。

【日期】
本版同時修正 D-Day 日期計算，改用使用者電腦的本地日期，避免台灣時區因 UTC 轉換產生一天偏差。

【安全】
目前維持你正在測試的內部模式。如果日後正式部署並啟用員工登入，再執行 02_正式上線_登入與安全模式_選用.sql。
