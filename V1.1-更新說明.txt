GUXON 新品專案管理 V1.1

本版是在你目前已可正常連線 Supabase 的 V1 專案上直接升級。

新增／改善：
1. 首頁 Dashboard：全部專案、進行中、已完成任務、卡關任務。
2. 首頁每個專案直接顯示完成百分比。
3. 員工管理可直接修改姓名、部門、Email、啟用／停用。
4. 任務名稱可直接修改並保存 Supabase。
5. 可刪除整個專案（會先跳確認）。
6. 新增／刪除／更新任務時同步首頁統計。
7. 保留 V1 原有：六階段、負責人、日期、狀態、備註、逾期提醒、新增專案、自動產生六階段、列印 PDF。

安裝方式：
- 保留你電腦原本的 .env.local。
- 將本資料夾 app 覆蓋原專案 app。
- 其他檔案原則上不需動。
- PowerShell 停止 npm run dev 後重新 npm run dev。

注意：
目前仍屬內部 V1 系統，尚未加入員工登入與權限控管。正式公開到網路前，應先加入 Supabase Auth 與 authenticated RLS。
